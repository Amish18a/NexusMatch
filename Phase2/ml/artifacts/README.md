# Frozen Trust Artifacts

This directory contains the small artifacts required by the frozen Phase 2 Trust inference path.

## Files

- final_trust_model.joblib — calibrated Trust model package
- final_test_metrics.csv — final unseen-test metrics
- validation_model_comparison.csv — chronological validation model comparison
- final_feature_importance.csv — model feature coefficients/importance when generated

Large datasets and prediction exports are intentionally stored under Phase2/data/ml/ and ignored by Git.
