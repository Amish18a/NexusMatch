# Phase 2 ML Experiments

These experiments document the model-selection and research work that led to the frozen Phase 2 Trust pipeline.

## Included

- prepare_future_window_dataset.py / train_future_window_models.py
- prepare_temporal_dataset.py / train_temporal_models.py
- train_temporal_nlp.py

The experiments operate on generated or processed data under Phase2/data/. Their outputs are ignored by Git.
